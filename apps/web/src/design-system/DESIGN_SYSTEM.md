# Arken Design System — Руководство и Базовые Правила

> Статус: Активный стандарт.
> Стек: `@base-ui/react` + Semantic CSS Tokens + Lucide Icons.

---

## 1. Философия продукта: «Живой цифровой театр и тактильная летопись»

Интерфейс Arken Space — это не сухая бухгалтерская таблица и не витрина неоновых градиентов. Это **живой цифровой театр в духе лучших современных столов (Alchemy RPG)**, создающий кинематографичное погружение у игроков и служащий незаметным, легким режиссерским пультом для мастера.

### Шесть фундаментальных принципов:

1. **Кинематографичный театр, а не таблица**: максимальный фокус на драме истории, мгновенный отклик 60 FPS, отсутствие визуальной перегрузки.
2. **Примат тактической карты (Map Primacy)**: поле боя — главный герой экрана. Панели интерфейса плавают над сценой с деликатным стеклянным размытием (`backdrop-filter: blur(14px)`).
3. **Избавление от «сотен обводок» (De-Bordering)**: отказ от жестких черных рамок `border: 1px solid #444`. Разделение строится на светотени, фоновых слоях (`--surface`, `--surface-raised`), мягких фасках света и деликатных границах `--border-subtle`.
4. **Персональные темы игроков**: 7 индивидуальных палитр (`forest`, `dragons`, `ice`, `fire`, `gold`, `silver`, `light`) для каждого участника сессии. Полная свобода игрока настраивать своего персонажа и способности.
5. **Постепенная автоматизация рутины (Cognitive Offloading)**: постепенный перенос вычислительной нагрузки (ресурсы, кошелек, броски) с мастера на систему.
6. **Гибкая плотность и мультиплатформенность (Fluid Density)**: плотный режим для мастера, просторный кинематографичный режим для игроков, поддержка мобильных устройств, планшетов и режима Split-Screen (пол-экрана).

## 2. Палитра: Warm Ink & Terracotta Clay

- **Фон (Canvas)**: `--palette-ink-900` (`#181816`) — глубокий, теплый, несвекольный темный фон.
- **Поверхности (Surfaces)**:
  - Базовая: `--palette-ink-800` (`#20201d`)
  - Приподнятая (Raised / Карточки, модалки): `--palette-ink-700` (`#292824`)
  - При наведении (Hover): `--palette-ink-600` (`#34322c`)
- **Границы (Borders)**:
  - Базовая 1px: `--palette-ink-500` (`#47443b`)
  - Активная 1px: `--palette-ink-400` (`#696356`)
- **Акцент (Action / Accent)**:
  - Основной: `--palette-clay-500` (`#c46f49` — обожженная терракотовая глина)
  - Hover: `--palette-clay-400` (`#d57d55`)
- **Текст**:
  - Основной (Primary): `--palette-ink-100` (`#e8e4da` — теплый пергаментный белый)
  - Второстепенный (Muted): `--palette-ink-200` (`#aaa598`)
  - Подписи (Faint/Caption): `--palette-ink-300` (`#777267`)

## 3. Пространственная сетка и закон близости (Spatial Scale)

Базовая сетка кратна 4px и 8px:

| Токен         | Значение | Назначение                                                  |
| ------------- | -------- | ----------------------------------------------------------- |
| `--space-2xs` | `2px`    | Микро-сдвиги, рамки, индикаторы                             |
| `--space-xs`  | `4px`    | **Микро-связь**: лейбл к полю ввода, иконка к тексту кнопки |
| `--space-sm`  | `8px`    | **Тесная группа**: связанные элементы строки, чипы          |
| `--space-md`  | `12px`   | **Мезо-связь**: расстояние между соседними полями ввода     |
| `--space-lg`  | `16px`   | **Контейнер**: внутренний паддинг карточки/панели           |
| `--space-xl`  | `24px`   | **Макро-связь**: между смысловыми группами/секциями         |
| `--space-2xl` | `32px`   | Разделители крупных зон интерфейса                          |

### Ритм формы (Form Layout Hierarchy):

```
[ Заголовок группы / Section Title ]  (14-16px, semibold)
    ↓  --rhythm-field (12px)
[ Лейбл / Label ]                     (11px, muted)
    ↓  --rhythm-micro (4px)           ← Лейбл жестко привязан к своему полю!
[ Контрол ввода / Input ]             (32px)
    ↓  --rhythm-field (12px)          ← До следующего поля в этой же группе
[ Лейбл второго поля ]
    ↓  --rhythm-micro (4px)
[ Контрол второго поля ]
    ↓  --rhythm-section (24px)        ← До следующей смысловой группы!
[ Следующая группа / Fieldset ]
```

## 7. Каталог компонентов

- [x] `Button` (`Button.tsx`, `Button.css`) — standalone, размеры `xs`..`xl`, стили `normal`, `action`, `flat`, `outlined`, `raised`, `danger`, `success`.
- [x] `Input` (`Input.tsx`, `Input.css`) — standalone на `@base-ui/react/input`, slots, clear, pins, валидация.
- [x] `TextArea` (`TextArea.tsx`, `TextArea.css`) — standalone многострочный ввод с автоподстройкой высоты.
- [x] `Checkbox` (`Checkbox.tsx`, `Checkbox.css`) — standalone на `@base-ui/react/checkbox`, кастомный индикатор, фокус-контур.
- [x] `Switch` (`Switch.tsx`, `Switch.css`) — standalone на `@base-ui/react/switch`, плавное переключение, тактильный тумблер.
- [x] `Dialog` (`Dialog.tsx`, `Dialog.css`) — standalone на `@base-ui/react/dialog`, Compound API (`Header`, `Body`, `Footer`), клавиша Escape, ловушка фокуса.
- [x] `Select` (`Select.tsx`, `Select.css`) — standalone на `@base-ui/react/select`, всплывающий список с поиском и клавиатурной навигацией.
- [x] `Badge` (`Badge.tsx`, `Badge.css`) — индикаторы статусов, ролей доступа («Мастер», «Игрок») и состояний.
- [x] `Loader` (`Loader.tsx`, `Loader.css`) — индикаторы загрузки (спиннер в палитре терракоты и угля).
- [x] `Popup` (`Popup.tsx`, `Popup.css`) — плавающие тултипы и меню на позиционировании.

## 8. Игровые макро-паттерны (Tabletop Game UX Patterns)

1. **Hero Header листа персонажа (`.character-hero`)**:
   - Аватар 56×56px или тактильный жетон с первой буквой имени.
   - Имя персонажа, бейдж уровня доступа, статус ревизии, переименование, быстрый режим броска и отдых.
2. **Vital Stats Bar (`.character-vitals`)**:
   - Фокусная строка чипов: кошелёк (зм/см/мм), пулы ресурсов (`текущее / максимум`), ключевые боевые параметры.
3. **Character Rail (`.character-rail`)**:
   - Боковая панель шириной 190–230px, аватары-жетоны, четкая подсветка активного листа терракотовым маркером `border-left: 3px solid var(--accent)`.

## 9. Публичный стенд Storybook

Стенд изолированно тестирует и демонстрирует всю дизайн-систему:

```sh
# Запуск интерактивного стенда разработки
pnpm --filter @arken/web storybook

# Сборка статичного продакшен-стенда
pnpm --filter @arken/web build-storybook
```

Стенд включает:

- Документацию философии и манифеста Anti-AI Slop.
- Витрину палитры, токенов, шрифтов и отступов.
- Каталог интерактивных компонентов с a11y тестированием.
- Игровые паттерны и правила механик.
