# Базовые правила: Цвета, Типографика, Сетка и Отступы

Интерфейс строится по строгим математическим правилам пространственной иерархии, исключающим слипание элементов.

## 2. Пространственный ритм и Закон Близости

Главная причина плохого восприятия интерфейса — отсутствие иерархии в отступах, когда лейбл, поле ввода и следующая секция имеют одинаковое расстояние и визуально слипаются.

В Arken Space действует строгое правило шага:

```
[ Заголовок секции / Section Heading ] (14-16px, semibold)
    ↓  отступ 12px
[ Лейбл поля ввода / Label ] (11px, muted)
    ↓  отступ 4px  ← Лейбл жестко привязан к СВОЕМУ полю!
[ Контрол ввода / Input ] (32px высота)
    ↓  отступ 12px
[ Лейбл следующего поля ]
    ↓  отступ 4px
[ Второе поле ввода ]
    ↓  отступ 24px ← До следующего смыслового блока!
[ Следующая секция / Fieldset ]
```

### Шкала отступов:
- `2px` (`--space-2xs`): микросдвиги индикаторов.
- `4px` (`--space-xs`): связь лейбла с инпутом, иконки с текстом.
- `8px` (`--space-sm`): плотная группа чипов или кнопок строки.
- `12px` (`--space-md`): расстояние между соседними полями ввода в одной группе.
- `16px` (`--space-lg`): внутренний паддинг карточек и модальных окон.
- `24px` (`--space-xl`): расстояние между смысловыми секциями интерфейса.
- `32px` (`--space-2xl`): макро-разделители глобальных зон экрана.

---

## 3. Высоты контролов (Control Heights)

- `xs` (**24px**): строки таблиц инвентаря, компактные чипы.
- `s` (**28px**): сайдбар стола, трекер инициативы, тулбары карты.
- `m` (**32px**): **канонический стандарт** полей форм и кнопок диалогов.
- `l` (**36px**): акцентные поисковые поля.
- `xl` (**44px**): мобильный тач-таргет по стандартам WCAG / Apple HIG.

---

## 4. Скругления (Border Radii)

- `2px` (`--radius-xs`): тонкие полосы здоровья и таймлайна.
- `4px` (`--radius-sm`): **тактильный стандарт** кнопок, чекбоксов и полей ввода.
- `6px` (`--radius-md`): выпадающие списки (Select) и поповеры.
- `8px` (`--radius-lg`): карточки, модальные окна, панели сайдбара.
- `999px` (`--radius-pill`): круглые жетоны персонажей, бейджи, свитчи.
