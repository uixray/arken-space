## Производительность — сделано 15.10

- **Рассылка снапшотов** (`broadcastSnapshots`, около 70 мест вызова): раньше каждая запись пересобирала полный снапшот для каждого сокета. Теперь рассылки склеиваются по кампании (`broadcast-coalescer.ts`): одна в работе, плюс одна общая следующая.
- **Рендер карты:** 10 снапшотов, не меняющих карту, давали 40 перерисовок рендерера, теперь 0. Причины: структурное разделение снапшота (`structural-sharing.ts`), проекция токенов без лишних массивов, стабильные колбэки.
- **Бандл:** ленивая загрузка шести рабочих пространств (−21 KiB gzip) была сделана и **откатана**: CSS ленивых чанков подключался позже основного и менял каскад (в Firefox при ширине 390 обрезалось поле тегов в редакторе мира; общие стили диалогов тоже ушли в отдельные чанки). Вернуть её можно после изоляции стилей рабочих пространств.

## Производительность — дальше

- UIX-412: точечные события вместо полной рассылки снапшота — главный оставшийся рычаг на сервере. Первый домен — рисунки (`drawing-events.ts`): мазок, правка, копия и удаление теперь дают 0 полных рассылок вместо 1 (пересборка снапшота на каждый сокет). Исключение — штампы из картинок кампании: им нужна запись в `snapshot.assets`, поэтому они остаются на полной рассылке. Событие уходит только после рассылки, которая уже в работе, иначе устаревший снапшот стёр бы рисунок. Отмена и повтор на канвасе по-прежнему рассылают полный снапшот. Второй домен — счётчики персонажа (HP, ресурсы, кошелёк, отдых, `character-events.ts`): `character:updated` мастеру, владельцу и контроллерам плюс строка в общий чат через `chat:created`, 0 полных рассылок вместо 1. Исключение — строка кошелька, слитая с предыдущей: события для изменения сообщения нет, поэтому там остаётся полная рассылка. Третий домен — состояния и цвета жетона (`token-events.ts`): `token:updated` ровно тем, у кого жетон есть в снапшоте (сцена, слой мастера, скрытость, туман), 0 полных рассылок вместо 1.
- Бандл: в стартовом коде около 270 KiB исходников `zod` (схемы контрактов попадают в клиент). Gravity UI убран 16.10 (UIX-709): JS 1353 → 1260 KB (392 → 362 KB gzip), CSS 363 → 280 KB (57 → 48 KB gzip).
