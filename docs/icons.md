# Иконки интерфейса: Lucide

Решение владельца от 06.09.2026, задача **UIX-645**: все авторские UI-иконки
используют **Lucide**. Текстовые символы, Unicode/emoji, HTML entities и CSS
`content` вместо иконок запрещены. Правило действует и для новых элементов,
и для полной миграции существующих мест в рамках UIX-645.

## Подключение

`lucide-react` — локальная runtime dependency пакета `@arken/web`, с точной
версией в manifest и lockfile. Установка воспроизводится через
`pnpm install --frozen-lockfile`. Лицензия ISC находится в установленном пакете.
SVG включаются в web bundle: не нужны CDN, icon font или сетевые запросы за
иконками во время игры.

Канонический entrypoint — `apps/web/src/ui/icons.ts`: добавляйте только нужные
именованные exports из Lucide, при необходимости с семантическим алиасом.
Нельзя использовать `import *`, полный каталог `icons`, `DynamicIcon` или
динамическую загрузку набора ради обычной UI-кнопки. Именованные экспорты
сохраняют tree shaking.

```tsx
import { AppIcon } from "./ui/AppIcon";
import { CloseIcon } from "./ui/icons";

<button type="button" aria-label="Закрыть окно" onClick={onClose}>
  <AppIcon icon={CloseIcon} />
</button>;
```

## Контракт

- `AppIcon`: размеры 16 / 20 / 24 px, по умолчанию 16; stroke 2;
  `currentColor`, без локальных жёстко заданных цветов.
- Размер SVG не определяет hit-area: сохраняйте размеры и focus state кнопки.
- SVG декоративный: `aria-hidden="true"`, `focusable="false"`. У icon-only
  кнопки обязательна понятная подпись `aria-label`; tooltip её не заменяет.
- Для самостоятельного индикатора нужен внешний текст/доступное имя на
  семантическом контейнере. Не пытайтесь сообщить статус только иконкой/цветом.
- Не передавайте обработчики действий самому SVG: действие принадлежит кнопке.
- Не меняйте layout, игровые права и handlers при замене изображения иконки.

Обычная пунктуация, математические операторы в формулах, подписи горячих клавиш,
пользовательские сообщения, emoji/стикеры и игровой контент не являются
псевдоиконками. Не удаляйте их массовой заменой Unicode.

## Миграция и gate

Foundation не означает, что весь интерфейс уже переведён. Начальное реальное
использование: закрытие и сброс расположения workspace-окон в `ArkenDialog`.
Gravity UI остаётся библиотекой компонентов; существующие потребители
`@gravity-ui/icons` мигрируют отдельно, пакет не удаляется преждевременно.

Полный реестр мест, SVG-миграция всех символов-иконок, browser QA и
автоматическая anti-glyph проверка (JSX, строковые конфиги, entities, CSS)
остаются обязательными этапами **UIX-645**. Не считать документ или установленную
зависимость автоматической защитой от регрессий. Непроверенные пункты не
объявлять выполненными.

### Локальный следующий пул: карта и панель, 2026-09-12

В ветке UIX-645 подготовлены реальные SVG для панели карты, кистей/полигонов
тумана, курсоров, сетки/масштаба карты, истории и сворачивания Sidebar. У всех
контролов сохранены обработчики и доступные имена. Различимость Pentagon и
Hexagon важна именно в свёрнутом состоянии, где текст скрыт. Это ещё не
интегрированный main и не browser acceptance.

`scripts/ui-icon-policy.mjs` и `tests/ui-icon-policy.test.ts` добавляют scoped
AST/CSS-проверку: список защищённых файлов явно перечислен, тест читает их
актуальное содержимое, отрицательные примеры не подменяют исходники копиями.
Существующий hosted `pnpm test` включает этот тест без отдельного сервиса.
Пока gate не выполнен, это **подготовленная проверка**, а не доказанная защита.

Охват не равен всему приложению: исходный список — диалоги, карта, Sidebar,
курсор, сетка/история, музыка/пауза и icon entrypoint; CSS только toolbar/grid/resize.
Обычные сообщения, формулы, хоткеи и непройденные области не фильтруются этим
списком. При следующем migration-пуле явно расширять список вместе с тестом,
не делать вид, что десять файлов покрывают все интерфейсы.

Полный оставшийся реестр и этапы: [migration checklist](./icons-migration.md).
