# Первый вход в Аркспейс

## Онлайн-версия

1. На главной странице откройте вход в аккаунт. Зарегистрируйтесь и подтвердите
   почту, если аккаунта ещё нет.
2. В «Моих кампаниях» создайте кампанию, указав название. Система — Аркен-Хар;
   отдельный выбор других игровых систем сейчас не предлагается. Первая пустая
   сцена создаётся автоматически.
3. Откройте игровой стол, подготовьте сцену и персонажей.
4. В карточке кампании создайте личное приглашение игроку. Игрок входит в свой
   аккаунт, принимает приглашение и открывает кампанию. В разделе «Персонажи»
   он может создать свой лист по договорённости с мастером.

Приглашение — доступ к кампании. Передавайте его лично, а не в публичном чате.
Постоянная раскрывающаяся инструкция «Как начать игру» доступна в «Моих кампаниях»
после перезагрузки и повторного входа. Мгновенная подсказка после создания
кампании дополняет её, но не является единственным способом найти инструкцию.

## Автономная Windows-версия

Предварительный установщик рассчитан на Windows 11 x64. Используйте полный
EXE из доверенного комплекта автора. Выберите новую папку программы на локальном
диске; каталог программы и данные партий хранятся отдельно. Компоненты среды
выполнения включены в комплект: отдельно устанавливать Docker, Node или
PostgreSQL не требуется.

После установки откройте «Arken Space — локальный сервер» и следуйте встроенной
справке для подготовки сервера и первого аккаунта мастера. Локальный вход
использует логин и пароль, без подтверждения email. Затем откройте браузерный
интерфейс и создайте кампанию.

По умолчанию сервер доступен на компьютере хозяина. Адрес localhost нельзя
использовать как приглашение на другом устройстве. Настройка доступа по HTTPS
в локальной сети — отдельный шаг в интерфейсе локального сервера; фактическая
работа второго устройства требует отдельной приёмки. Не открывайте порты и не
отключайте защиту Windows ради обхода ошибки установки.

При ошибке Setup сохраните указанный код этапа и журнал установщика. Для
предварительного пакета 0.1.1 выполнены разбор исходников и компиляция;
это не заявление о пройденной установке на компьютере пользователя.

## Границы

Этот путь не включает оплату, магазин расширений или другие игровые системы.
Работа с реальными новыми пользователями и физическими мобильными устройствами
учитывается отдельно. Техническая реализация первого входа не заменяет такие
исследования.
