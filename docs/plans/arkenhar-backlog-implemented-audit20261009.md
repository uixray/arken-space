## Cross-cutting conclusions

1. “Open in Linear” frequently means a gate or product decision remains even where code is substantial. The clearest integration gaps are UIX-382 (backend multi-track model without a web consumer), UIX-457 (resolver contract without consumers), and UIX-245/UIX-264 (canonical content UI/API without campaign instances or chronicles). UIX-505 is intentionally suspended by owner decision UIX-621, not a gap to fill unilaterally.
2. Several asks share prerequisites rather than being independent implementation starts: UIX-265 depends on item instances + regional/calendar contracts; UIX-459 depends on editable UIX-458 school progression; UIX-430 requires target/range/resource authorization decisions; UIX-588 needs reroll semantics; UIX-496 needs a product decision on player skill-add approval/limits; UIX-495 needs a shared-vs-private notes decision.
3. Current source/tests are not runtime acceptance. This document is an implementation audit only: no test command or browser gate was run. All 35 Linear statuses remain unchanged.
