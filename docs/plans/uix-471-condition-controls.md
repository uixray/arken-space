# UIX-471 — Управление состояниями токена

Продолжение согласованного пула UIX-620, база `6910b86`.
Заявка In Progress в Linear; общие UI-файлы освобождены владельцем.

Сервер, контракт четырёх состояний, значки и подсказки уже реализованы.
Подтверждённый пробел: web не вызывает PATCH `/api/tokens/:id/conditions`.
Существующий закрытый набор и правила видимости сохраняем без миграций.

Добавляем четыре переключателя в меню токена только для GM. Используем
текущий токен из props, а не устаревшую копию при открытии меню. Одно действие
закрывает меню и отправляет весь набор с revision/actionId. Оптимистической
подмены нет: состояние приходит от сервера; ошибки обрабатывает общий `run`.
После успешной команды `run` обновляет snapshot; отклонённая команда не
подменяет состояние и не создаёт необработанного Promise rejection.

Проверка: компонентная установка/снятие с сохранением соседнего состояния,
ограничение роли, актуальная ревизия; диверсия. UI-провод до HTTP и отображение
требуют браузерной проверки. Общие E2E/quality — на границе UI-пула.

## Контрольная точка

Реализовано в App.tsx, SceneRenderer.ts, Orthographic2DRenderer.tsx,
TokenConditionMenu.tsx и styles.css. Новый DOM-тест и сценарий в
canvas-token-regressions.spec.ts. Отдельно исправлен id секции тестовой
фикстуры SkillCards.test.ts из предыдущего среза: `characteristics`, не `stats`.

- DOM: 2/2 PASS (GM, сохранение соседнего состояния, revision из snapshot,
  отсутствие управляющих элементов у PLAYER).
- Диверсия DOM: потеря предыдущего состояния вызывает ровно ожидаемое
  падение, код 1; восстановление — 2/2 PASS.
- Web typecheck после исправления фикстуры — PASS.
- Адресный браузерный сценарий с mock API: Chromium + Firefox, 2/2 PASS,
  17,9 с. Установка, совмещение, снятие, actionId/revision и отказ 409.
- Диверсия App→HTTP: неправильный URL приводит к отсутствию ожидаемого
  PATCH, ровно этот сценарий падает (код 1). Восстановление — 2/2 PASS.
  Первый запуск диверсии не засчитан: страница не загрузилась до меню;
  проверку повторили на готовом Vite с пересобранным dependency cache.
- Производственные файлы после диверсий восстановлены точными байтами.
  Dev-сервер остановлен, порт 5188 освобождён.

Блокеров реализации нет. Это не полный E2E и не новый multiplayer gate:
итоговая приёмка остаётся на границе UI-пула. Следующий срез — UIX-584.
