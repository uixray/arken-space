# UIX-621 — сначала токены и броски

## Решение владельца

Второстепенный бэклог остановлен. Бой убирается из пользовательского интерфейса без удаления данных. Приоритет: рабочие меню, мгновенные действия с токенами, броски и боковая панель.

## Связанные части пула

1. UIX-502: dropdown над модалками; UIX-416/472: видимое меню «Ещё».
2. UIX-471: компактные статусы и безопасные быстрые переключения.
3. UIX-396/491/589: optimistic placement/move с rollback и rebase, без глобальной задерживающей очереди.
4. UIX-507: рамочное и множественное выделение; UIX-405/463: Ctrl+клик Ping.
5. UIX-406/504/472: броски и боковая панель. Удаление UI боя.

## Приёмка

Сначала воспроизведение на точном production baseline f1a66c8 и замер click-to-paint при искусственной задержке сети. Пользовательский результат обязан появляться до ответа сервера; сервер подтверждает/откатывает его асинхронно. Не подменять optimistic результат выдуманным итогом броска: итог авторитетен, сам бросок/ожидание видны немедленно.

Для меню проверяется фактический hit-test в production build, а не только наличие DOM. Для статусов — быстрые последовательные клики до ответа, сохранение объединённого результата. Для токенов — несколько размещений подряд без ожидания предыдущего.

Один связанный browser/quality gate после пула. Диверсии только на новых регрессиях. Не тратить цикл на второстепенные задачи.

## Интеграционный срез: базовый игровой контур

- Revision: база f1a66c8; изменения пока локальные, без коммитов/публикации.
- Решения: основной UI боя отключён, исторические данные не удаляются; кости доступны прямо на карте независимо от вкладки боковой панели. Видимость бросков общая, результат броска остаётся серверным, ожидание видно сразу.
- Изменённые группы: App/MapToolbar/WorldMapsWorkspace; sidebar ChatPanels/DiceTray и контекст видимости; renderer/TokenConditionMenu/подписи статусов; optimistic-token-mutations/use-token-definition-actions; CSS слоёв и компактной строки; адресные DOM/browser/multiplayer-тесты.
- Проверено: рамка → групповое перетаскивание мышью; три статуса видны до первого подтверждения и сохраняются объединённым запросом; pending изображения двух токенов появляются при удержанных ответах; отказ одного не откатывает второй. Адресные browser-прогоны зелёные, не замена полному гейту.
- Диверсии: выключение старта рамки, объединение строк статусов, отключение checked, удаление optimistic projection, возврат боевой кнопки и старого текстового режима приводили к адресным падениям; изменения восстановлены.
- Живой локальный API + отдельная одноразовая PostgreSQL: журнал не перекрывается на ширинах 280/360/600, composer виден на низком экране даже при сохранённом legacy-бое; 2/2 Chromium PASS.
- Обнаруженный остаток: websocket snapshot может прийти раньше HTTP placement ACK. Закрывается точной корреляцией ID, не эвристикой по координатам. Также проверяется неперекрытие костей и лотка токенов на узком экране.
- Следующий шаг: завершить эти две интеграционные проверки, затем один общий quality → production-build browser → multiplayer gate. До этого пул не принят и не готов к публикации.

## Итог локального пула, 2026-09-04

- Исправлено: «Ещё» и общий внешний слой Gravity Select (включая raw Select обратной связи); рамка ЛКМ и групповое перетаскивание; Ctrl+клик Ping; компактные построчные статусы с сохранением быстрых изменений; мгновенные независимые placements и адресный rollback.
