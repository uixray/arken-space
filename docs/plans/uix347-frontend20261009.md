## Defect and verification

A canonical stamp DTO with an empty `points` array reached the old freehand-only `drawingBounds()` path, which dereferenced `points.length` while selecting map objects and crashed the renderer. Fixed with a stamp-specific, rotation-aware bounds branch; no DTO/mock workaround.

A second late-ack race was found: the create response could append a stamp after a newer canonical snapshot had already deleted it, or after the GM selected another scene. The acknowledgement reconciliation now only inserts when campaign, selected scene, role, and snapshot version still match the request, and the returned DTO belongs to that requested scene. If a newer canonical projection already arrived, that projection stays authoritative.
