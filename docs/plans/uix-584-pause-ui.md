# UIX-584 — Интерфейс перерыва

Продолжение UIX-620 от `7021c8e`; заявка в Linear In Progress.
Серверная команда POST `/api/campaign/pause` и guards уже интегрированы.

План: GM control и немодальный overlay только внутри карты; authoritative
paused из snapshot, без оптимистического переключения. Чат и броски снаружи
карты остаются доступны. На паузе toolbar размонтируется вместе с глобальными
undo/redo listeners; renderer получает inert и null socket. Смена pause key
пересоздаёт renderer, очищая локальные draft/selection/жесты. Camera при этом
возвращается к исходному fit; сохранённые объекты карты остаются видимыми.
В App очищаются выделение, preview, encounter draft и эфемерные события.

Проверки связанного среза: роли, pause/resume, отказ сервера, доступность
карты/чата, reload и две ширины; адресная диверсия. Reconnect/multiplayer и
общие гейты — на итоговой ревизии пула.

Иллюстрация есть только в исходном рабочем дереве. Разрешение на добавление
единственного файла assets запрошено отдельно; до ответа каталог не меняем.

## Контрольная точка кодового среза

Реализованы GamePauseOverlay, подключение команды в App, inert renderer,
сброс pause key, очистка отложенных таймеров рисунка при размонтировании,
скрытие toolbar вместе с undo/redo listeners. Размещение из палитры во время
перерыва отключено, drag недоступен; чат и броски не закрыты overlay.

Файлы: App.tsx, GamePauseOverlay.tsx, SceneRenderer.ts,
Orthographic2DRenderer.tsx, TokenPalette.tsx, styles.css;
GamePauseOverlay.dom.test.tsx и canvas-token-regressions.spec.ts.

Проверка: DOM 2/2 PASS; адресный Chromium+Firefox — 8/8 PASS (GM/PLAYER,
1280/390 px, pause/resume, reload, inert, sidebar вне блокировки). Первичный
прогон обнаружил ширину overlay 640 вместо 390 px: ограничена через max-width,
общая минимальная ширина приложения не менялась. Web typecheck, E2E tsc и
scoped lint пройдены до заключительной правки палитры; общие гейты впереди.

Диверсии: снятие inert ломает ровно браузерный тест GM/1280 по атрибуту;
снятие проверки роли ломает ровно DOM-тест PLAYER. Код 1 в обоих случаях,
после восстановления браузеры 8/8 и DOM 2/2 PASS. Прогон подтверждает
reload, но не заменяет проверку живого reconnect и отправки chat/dice.

Осталось: разрешение на единственный artwork, его добавление и визуальная
проверка; сценарий живого reconnect/chat/dice и окончательные quality/E2E/
multiplayer на общей ревизии. До этого UIX-584 не Done. Production не трогали.

### Иллюстрация — разрешение получено

Владелец отдельно разрешил добавить только `game-pause-rest.webp`.
Исходный файл 198 914 байт скопирован без преобразований; остальные assets
не затронуты. Подключён как стандартная иллюстрация GamePauseOverlay.
`object-fit: contain` сохраняет весь сюжет; пустой alt обозначает декоративную
иллюстрацию, смысл состояния уже сообщают заголовок и live status.

Адресная проверка artwork: Chromium, 1280/390 px — 2/2 PASS (14,2 с).
Изображение действительно загружается (naturalWidth 1672), contain и alt
проверены; оба скриншота просмотрены — сюжет целиком, кнопка продолжения видна.
На mock-стенде есть уведомление об ошибке незамоканных вспомогательных API;
проверка изображения не считается чистой приёмкой живого приложения.
Лог `%TEMP%/arken584-artwork.log`, снимки `test-results/**/pause-artwork.png`.
Следующее действие: живой reconnect/chat/dice и итоговые гейты пула.
