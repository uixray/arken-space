## Границы проверки

Это сверка канонических инженерных документов, полного остатка Linear и
маршрута продолжения, **не аудит каждого исторического Markdown-файла** и не
исполнение всех будущих задач. Ранние пакеты UI содержат конкретные команды;
дальние Backlog-пулы требуют ограниченного discovery по исходной карточке,
а не считаются готовыми реализационными спецификациями.

Календарь сентября — января является предварительным планом: оценки уточняются
по измеренному остатку и человеческим gates. Не проверены реальными людьми:
GM+6, физические устройства, авторские playtests, полный theme/menu acceptance.
Персональные темы и область story media требуют решения владельца.

Предыдущий отказ auto-review на запись в Linear остаётся отдельным ограничением;
его не обходили. Полный реестр содержит внутренний проектный контекст и не
предназначен для публичного сайта без отдельной проверки приватности.
