## Проверка и контрольная точка

Для новых регрессий — адресная проверка и диверсия производственного кода.
Общие гейты на границе связанного пула, а не после каждого метода:
`pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm build`, `pnpm test`.
Для UI — E2E; для доступа и realtime — multiplayer с Docker.
Код возврата фиксируется непосредственно, без маскирующих конвейеров.

На момент старта зависимости установлены отдельной offline frozen-lockfile
установкой; изменения UIX-448 перенесены без изменения исходного рабочего дерева.
Общие гейты новой ревизии ещё не пройдены. Следующее действие: завершить
контекст подписей, проверить регрессию и интегрировать оставшиеся три ветки.
