# Веб-пул и айдентика — release scope 02.11.2026

## Решение владельца

«Сначала веб-пул и айдентика; остальное отдельным обновлением».
Разрешены commit/push/merge, сборка release-артефактов и публикация с последующими
операционными проверками. Новый тестовый CI, тесты, квалификация и бэкап не заказаны.
Существующие бэкапы сохраняются; минимальный свободный резерв сервера — 3 ГиБ.
Удаление ранее не согласованных серверных данных требует отдельного решения.

## Состав

- UIX-365: личный чат/unread и согласованные исправления интерфейса.
- UIX-625–628: мобильный вход, жесты карты/токенов, инструменты и меню мастера.
- UIX-318: ручное подтверждение текста операторского отчёта перед копированием.
- UIX-430: область способности, масштаб сцены и автоматический выбор персонажей
  игроков; один общий серверный бросок по согласованной механике.
- UIX-715: статичные фигурки, направления/состояния и сохранение круглых токенов.
- Структурированный инвентарь и UIX-265: магазины, серверные цены и атомарная покупка.
- UIX-245: регион/эпоха и фильтры; не расширение исходного согласованного пула.
- UIX-525/526/657: связанный первый вход Аркен-Хар. Создание кампаний — для
  подтверждённых email-аккаунтов; существующий лимит не увеличивается.
- UIX-687 / часть UIX-269: очередь Telegram-багов, правки/альбомы, подтверждение
  оператором. Код поставляется выключенным; бот и отправляющий worker не активируются.
- UIX-768: персональные названия костей по точному membership, не по имени.
  Пустая конфигурация сохраняет обычные названия; активация фиксируется отдельно.
- UIX-708: опциональные измерители snapshot, не изменение wire-событий.
- UIX-506: принятые А2/Б2 + временный Yeseva One; локальные ассеты с лицензией,
  favicon, публичный вход/аккаунт и компактный знак в игровой шапке.

## Граница Windows и схемы

Native host/launcher/archive-cipher, desktop entry и UIX-461 не входят в релиз.
Их локальные незавершённые исходники сохраняются. Общие account/runtime-модули
и схема LOCAL_HOST уже являются зависимостями web/server; они включены, но
production остаётся в HOSTED. Это не поставка или приёмка Windows-установщика.

В журнале 81 миграция. Добавляются 0068–0080 поверх опубликованных 68 записей.
Новые таблицы/поля не удаляют игру и инвентарь; email-аккаунты сохраняют обязательные
email-поля через identity constraint. Перед активацией сверяются точные старые
ledger hashes и новый schema label. Миграции ещё не исполнялись этим релизом.

## Доказательства и ограничения

Исходники проверялись связанными пулами, но весь новый runtime/ACL/мобильные жесты
и миграции не квалифицированы. Наличие исходников не является PASS. Ранее записанные
проверки старых ревизий не переносятся на этот пул. Старые незавершённые продуктовые
критерии не закрываются автоматически фактом публикации.

Точное SHA, состав/хеши артефакта, дисковый расчёт и post-publication evidence:
`.data/web-pool-identity-release-20261102/` основного checkout (локальный журнал).
После публикации: revision/schema/API/БД, сохранение метрик и heartbeat,
frontend/assets, WebSocket и соседние сайты. Проверка этих операций не заменяет
полную приёмку продуктовых сценариев.
