Дата: 2026-11-02. **Владелец принял форму А2/Б2, затем отдельно разрешил внедрение и выпуск веб-пула с айдентикой. Веб-исходники подключены; публикация ещё не подтверждена.**

## Решение владельца

- Основной знак уже выбран: оригинальный Келзериас, без нового конкурса направлений.
- Предыдущие малые SVG А/Б не приняты: требуется приблизить форму к оригиналу.
- После коррекции владелец ответил: **«Принимаю А2/Б2»**. Принята новая оптическая
  пара, а не прежние А/Б; оригинал сохраняется. Это приёмка формы, не технический PASS.
- Для написания «Аркспейс» выбран **Yeseva One**. Это временный шрифт до будущего
  собственного АркенХара; его готовность и интеграция пока не заявлены.
- В дизайн-пакете изменены только редактируемые SVG и локальный лист сравнения.
  Предыдущие четыре SVG, оригинал, растровые исследования и все шрифты сохранены.
- После отдельного разрешения принятые SVG и оригинальный Yeseva One TTF/OFL
  скопированы в web/public без изменения байтов. Знак подключён к favicon и шапке,
  написание «Аркспейс» — к публичному входу и аккаунту. Интерфейс остаётся на
  Pragmatica; будущая замена wordmark изолирована в --font-family-brand.

[Лист сравнения](index.html): оригинал → прежний Б → новый Б2; затем А2/Б2
на двух поверхностях в 16/24/32/48 CSS px и связка с выбранным Yeseva One.
Прежние А/Б и невыбранные шрифты остались в раскрываемом разделе истории.
В уже открытом листе нужно обновить страницу: заголовок новой версии — «Ближе
к оригинальному Келзериасу».

Лист использует только локальные файлы. Интерфейсные tokens и Pragmatica Next
подключены относительными путями из checkout; это не разрешение распространять
Pragmatica отдельно. Для переноса листа необходимо сохранить зависимости или
согласовать другой интерфейсный шрифт.

## Что изменено в геометрии

- Вытянутая маска разделена на верхний гребень, центральную пластину, надбровье,
  щёки и длинное нижнее острие вместо прежнего короткого широкого силуэта.
- Изгиб рогов, их основание и тонкие верхние концы построены по оригиналу.
- Крылья получили каскад из лезвий с отдельными внутренними прорезями.
- Кардинальные украшения кольца — полые ромбы. У Б2 двойное кольцо; у А2 одно,
  более толстое, с увеличенными просветами и меньшим количеством мелких линий.
- Цвет/свечение и металлическая текстура не переносятся в малый монохромный знак.

Это ручная интерпретация, а не точная трассировка. Форма принята владельцем;
эта приёмка не доказывает техническую читаемость во всех малых размерах.

## Файлы и оптические роли

- `reference/kelzerias-original.png` — точная копия выбранного оригинала.
- `marks/kelzerias-micro-v2-{dark,light}.svg` — А2, проба для 16 px.
- `marks/kelzerias-small-v2-{dark,light}.svg` — Б2, проба для 24–48 px.
- `marks/kelzerias-micro-{dark,light}.svg` и
  `marks/kelzerias-small-{dark,light}.svg` — прежние А/Б, не изменены.
- `dark` — тёмные линии для светлого фона; `light` — светлые для тёмного.
  Фон, глаза и прорези прозрачны. Прямоугольники в luminance-масках не рисуют фон.
- V2 использует native SVG path/circle, внутренние use и маски. Нет встроенного
  PNG, внешних ссылок, шрифтов или скриптов в самих SVG.
- HTML показывает **эти же внешние SVG через img**; отдельной копии геометрии
  в inline-symbols больше нет. Это не компонент и не тема приложения.
- `reference/raster-study-*.png` — прежние image_gen-исследования с остаточной
  фактурой; не приняты как favicon. [Исходные промпты](generation-prompts.md)
  сохранены. Для V2 image_gen не применялся: отредактированы native SVG.

А2/Б2 — оптическая пара одного направления, не два новых логотипа.

- Ни новая геометрия, ни этот инвентарь **не являются PASS или закрытием UIX-506**.
