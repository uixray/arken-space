## Разница вариантов

1. **Картуш:** компактная табличка с внутренней рамкой. Рекомендуется для плотной
   карты за меньший декоративный footprint; это дизайн-рекомендация, не результат usability.
2. **Лента:** более выраженная бумажная форма. Боковые выступы нужно учитывать
   при размещении/ограничении у края; текст нельзя обрезать вместе с хвостами.

Оба варианта статичны. Рамка не заменяет название изображением и не является
отдельной интерактивной зоной. Обычные подписи — default для старых карт.

## Что показало чтение owning sources

`WorldMapsWorkspace.tsx` уже выводит location.name текстом внутри кнопки, задаёт
полное aria-label и привязывает маркер к нормализованным location.x/y.
`styles.css` содержит обычную pill-подпись. Декоративный режим/отдельное смещение
текста этим просмотром не найдены; это не повод менять сами координаты локации.

Название сцены имеет другой жизненный цикл, чем location marker. До реализации
нужно выбрать: локации, название сцены или оба места. Для обоих предлагается
раздельная настройка, без создания второй копии канонического названия.

Предлагаемый контракт после согласования:

- location: anchor остаётся географическим; GM меняет только смещение подписи;
- scene title: отдельный UI-элемент с выбираемым положением вне обязательных
  контролов, не переименование/перемещение игрового объекта;
- видимость получает готовую роль-фильтрованную модель, а не новый публичный каталог;
- текст сохраняет читаемый экранный размер при pan/zoom; compensation и clamping
  реализуются в owning canvas, а не объявляются выполненными этим макетом;
- оформление/положение сохраняются сервером с текущими правами GM и revision CAS;
- смена режима на обычный не удаляет название/положение самой локации.
