Что предлагаем сохранить в реализации

  1. По умолчанию — обычная подпись. Декор включает мастер; старые карты не меняют вид сами.
  2. Название и права — прежние. Скрытая локация не раскрывается из-за декоративной рамки.
  3. Смещается подпись, не точка локации. Положение можно вернуть к исходному.
  4. Текст не уменьшается вместе с картой. Компенсация масштаба и края экрана требуют реализации и отдельной проверки.
  5. Без анимации. Декор не перехватывает жесты; для фокуса и выбора есть отдельное обрамление.

Кнопки здесь служат образцами подписи и клавиатурного фокуса; не выбирают игровые объекты.
