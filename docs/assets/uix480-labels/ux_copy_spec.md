# UIX-480 — предлагаемые подписи интерфейса

Статус: черновик для выбора владельцем, не реализованные настройки приложения.
Обычный режим сохраняется независимо от выбранного декоративного направления.

| Место                                            | Текст                                                                               |
| ------------------------------------------------ | ----------------------------------------------------------------------------------- |
| Настройка маркера                                | Оформление подписи локации                                                          |
| Настройка названия сцены, если этот scope выбран | Оформление названия сцены                                                           |
| Режимы                                           | Обычное / Картографическое                                                          |
| Подсказка к режиму                               | Меняет только обрамление. Название и доступность локации остаются прежними.         |
| Перемещение                                      | Переместить подпись                                                                 |
| Подсказка к перемещению                          | Сдвигается подпись, не точка локации. Уберите её от фигурок и элементов управления. |
| Сброс                                            | Вернуть положение подписи                                                           |
| Сохранение                                       | Сохранить оформление                                                                |
| Конфликт ревизии                                 | Оформление уже изменилось. Обновите данные перед сохранением.                       |
| Потеря доступа                                   | Вы больше не можете менять оформление этой карты.                                   |
| Ошибка сохранения                                | Не удалось подтвердить сохранение. Проверьте текущее оформление перед повтором.     |

Текст названия выводится обычным DOM/семантическим текстом. Декоративные части
скрыты от accessibility tree. На управляющей кнопке остаётся полное название
локации; знак выбранного объекта не заменяется только цветом декора.

В одном продукте не предлагаются одновременно два новых набора настроек стиля:
картуш и лента — варианты для выбора, а не две автоматически добавленные функции.
Окончательные поля зависят от решения о локациях/названии сцены/обоих местах.
