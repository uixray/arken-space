# UIX-430 — область способности, локальный пул

## Принятые границы

- Мастер задаёт сцене `grid.metersPerCell`; старым сценам масштаб не придумывается. Линейка остаётся в клетках.
- Структурированный эффект способности: восстановление маны, круг от применяющего, радиус в метрах. Для «Лучезарного» — 15 м и существующий лимит одно использование в день.
- Автоматически выбираются активные персонажи, принадлежащие PLAYER-участникам текущей кампании, с фигуркой в области на текущей сцене. Включая применяющего, если это персонаж игрока. Один персонаж — один эффект, даже при нескольких фигурках.
- Расстояние между центрами фигурок, граница круга включена. Один общий серверный 1к6, существующий максимум маны не превышается. Обычная 2D-карта; не произвольная точка, высота, стены или новая модель союзников.
- Требование владельца: область должна быть видна в интерфейсе до применения.

## Собранный путь

1. В редакторе способности включить восстановление в области, указать радиус и отдельно существующий лимит/стоимость. Выданные ранее способности автоматически не переписываются.
2. Карточка и быстрые действия показывают радиус; «Показать область на карте» открывает локальный предпросмотр, без броска и расхода.
3. Единственная доступная фигурка выбирается сразу; если их несколько, пользователь явно выбирает размещение. На карте — полупрозрачный круг и радиус в метрах, в панели — описание эффекта. Без масштаба/фигурки — понятное предупреждение, применение недоступно.
4. Подтверждение отправляет только идентификаторы и ревизии. Сервер сам получает цели, бросает 1к6 и атомарно сохраняет ресурсы, одно использование/стоимость и запись журнала. Отдельные rollActions не дублируют эффект.
5. Отмена/Escape до отправки ничего не меняют. Смена сцены, участника, предпросмотр игрока и перерыв снимают неподтверждённый предпросмотр. После отправки сетевой таймаут не считается отменой: сохраняется тот же actionId/запрос для явного повтора, без повторного эффекта при наличии квитанции.

## Связанные инварианты исходников

- Геометрия общая: `packages/contracts/src/ability-area-geometry.ts`; круг UI основан на каноническом snapshot, не на локальном перемещении или несохранённой сетке.
- Сервер использует актуальную связь `tokenDefinitions.characterId`, не устаревающую копию в размещении `tokens.characterId`.
- Кампания блокируется раньше персонажей, как в canvas/pause; персонажи — по ID. SERIALIZABLE, без автоматического повтора транзакции. Проверяются ревизии способности, сцены и фигурки применяющего; цели берутся на момент применения.
- Только GM/владелец/управляющий может применить способность персонажа. Для игрока источник должен быть на активной сцене и доступен с учётом слоя/видимости/тумана. Данные целей, бросок и значения ресурсов от клиента не принимаются.
- Скрытые цели не раскрываются в UI, API-ответе или общем журнале. Обновления идут через существующие ролевые snapshot-проекции. GM-применение записывается GM_ONLY, чтобы не раскрыть скрытый источник; игрока — PUBLIC. Рамка броска выбирается существующим серверным механизмом.
- Потеря ответа: повтор требует того же участника и точного хеша команды; подтверждённая операция возвращает квитанцию до проверки устаревших ревизий. Ошибка последующей рассылки не превращает commit в отказ применения.
- Отсутствующий/невалидный ресурс маны у цели или неоднозначные старые стоимости блокируют весь эффект, без частичных изменений и без создания нового ресурса.
- Сброс визуальных настроек сетки сохраняет метрический масштаб. Новых SQL-миграций для области нет: поля хранятся в существующем JSONB.
