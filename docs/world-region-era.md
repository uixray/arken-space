# Регион и эпоха энциклопедии — UIX-245

Локальный согласованный пул. Не опубликован; миграция и runtime не проверены.

## Пользовательский сценарий

Мастер задаёт регион при создании или редактировании сущности. Регион — ссылка
на существующую сущность типа LOCATION, а не отдельный текст и не новая копия
описания локации. Самоссылка запрещена. Тип канонической сущности неизменяем в
обычном редакторе. Это плоская классификация, не дерево: рекурсивного обхода,
наследования региона или нового правила географической иерархии нет.

Эпоха — необязательная текстовая метка до 80 символов. Пробелы по краям
убираются. Фильтр сравнивает метку точно, без интерпретации дат. Календарь,
порядок эпох и существующая сортировка хроник по worldDay не менялись.

Оба фильтра находятся в менеджере мастера и энциклопедии игрока. Выбор региона
показывает максимум 40 названий; уточните поиск, если список длиннее. Текущий
регион запрашивается отдельно, поэтому не теряется за первой страницей.
Для снятия значения выберите пустой вариант. Для применения фильтров нажмите
существующую кнопку «Применить». «Обновить регионы» перечитывает варианты.

## Видимость и сохранение

- Игрок получает только доступные LOCATION по существующим правилам
  опубликованного/открытого в кампании канона. Скрытый регион не выдаёт ID
  или название в карточке. Фильтр по скрытому/несуществующему ID отвечает
  одинаковым 404; списка скрытых названий или счётчиков нет.
- Поисковый маршрут отдаёт только ID и название, не полный GM-документ.
- Список/карточка/варианты имеют private,no-store. После ошибки перечитывания
  старый список очищается. Возврат фокуса в открытую энциклопедию обновляет
  список и выбранную карточку. Это **не мгновенный серверный отзыв** уже
  показанных данных: постоянного polling или нового push-канала нет.
- Сохранение использует revision CAS. Изменённые поля региона/эпохи участвуют
  в сравнении, восстановлении черновика и разрешении конфликтов.
- Create/update связывают повтор с автором, операцией и хешем разобранного
  запроса. Точный повтор возвращает исходный DTO; другой запрос или старый
  неподтверждаемый receipt — 409. Прочие операции канона не переписаны.
- Регион защищён FK от удаления; новая миграция не угадывает значения у
  старых сущностей. Все существующие строки получают null.

## Остаток проверки

Миграция0070 подготовлена вместе с метаданными, не выполнялась. Нужны отдельно
разрешённые проверки типов/сборки, SQL, гонок, повторов, player/GM API, скрытых
регионов, DOM и узкой компоновки. Чтение исходников не доказывает эти сценарии.
Полный эпик245 дополнительно включает импорт/права источников, календарные
решения и приёмку; этот пул не закрывает его автоматически.
