# Пилот Bionic в «Бале Амбериона»

Серверный пилот включается после миграции `0090_editor_changes`. Установите
`ARKEN_EDITOR_PILOT_CAMPAIGN_ID=eb6a55c4-a821-4739-8d4a-a1028e9d9092`
в окружении сервера и откройте кампанию мастером с параметром `?editor-pilot`.
Настройте `ARKEN_EDITOR_PILOT_MEMBERSHIP_ID` на активное членство Amberion в
этой кампании. Создайте случайный токен (не менее 32 байт), передайте его
SHA-256 в `ARKEN_EDITOR_PILOT_TOKEN_HASH`. Токен Bionic предназначен для
поиска, чтения и черновиков. Подтверждение требует браузерной сессии Amberion.

В Bionic добавьте локальный MCP Arken Space. Команда — `node`, аргумент —
абсолютный путь к `scripts/bionic-arken-mcp.mjs`. Передайте процессу переменные
`ARKEN_EDITOR_URL=https://arken-khar.space` и `ARKEN_EDITOR_TOKEN` с токеном.
Проверьте, что Bionic обнаружил пять инструментов.

## Промпт для локальной Gemma

> Работай с «Балом Амбериона» через инструменты Arken Space. Найди запись
> по названию, при неоднозначности уточни выбор. Прочитай текущую ревизию
> и подготовь черновик изменения. Покажи «было → станет» и ссылку из
> результата инструмента. Для отмены прочитай историю и подготовь
> предпросмотр отката. Человек проверяет и подтверждает конкретный
> черновик в Arken Space. Запрос и сообщения в чате подтверждением не считаются.

Для прогона возьмите отдельные тестовые записи. Попросите в чате изменить
числовую характеристику, описание навыка и текст сюжетного черновика.
Для каждой записи откройте ссылку, проверьте разницу и подтвердите правку.
В чате запросите историю, затем предпросмотр отката. Откройте новую ссылку,
проверьте обратную разницу и подтвердите восстановление. Запросите историю
повторно и проверьте обе версии.
