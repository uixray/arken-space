# Инвентарь дизайн-системы — 25.08.2026

Фактический замер того, что используется в коде. Не оценка «на глаз»: каждая
цифра получена подсчётом и воспроизводима командами из раздела «Метод».

Ревизия: `f44b9bb`. Материал для §15 функционального ТЗ на интерфейс.

## Главный вывод

Дизайн-система **есть и спроектирована грамотно** — с семантическими именами
(`--color-surface-raised`, `--font-size-label`), а не «серый-1, серый-2». Это
важно: фундамент закладывался осознанно.

Но она почти не применяется. Типографика задаётся через токен **2 раза** и
сырым значением **123 раза**. Цвет — **2** против **53**.

Проблема не в отсутствии системы, а в том, что рядом с ней выросли ещё три.

## Четыре параллельных набора токенов

Одну и ту же поверхность сегодня можно задать четырьмя способами, и все четыре
встречаются в коде:

| Способ              | Пример                    | Где определён               |
| ------------------- | ------------------------- | --------------------------- |
| Семантический токен | `var(--color-surface)`    | `styles.css`                |
| Короткий псевдоним  | `var(--surface)`          | `styles.css`                |
| Gravity-слой        | `var(--arken-ui-surface)` | `ui/gravity-foundation.css` |
| Сырьё               | `#20201d`                 | по месту                    |

Активнее всего используются **короткие псевдонимы** — `var(--line)` 106 раз,
`var(--muted)` 91, `var(--accent)` 54. То есть фактическая система проекта —
это второй набор, а не первый, спроектированный.

## Что из Gravity UI

`@gravity-ui/uikit` подключён и используется в 52 файлах из 74, но как
библиотека готовых контролов, а не как дизайн-система:

| Компонент                                                      | Импортов |
| -------------------------------------------------------------- | -------- |
| `Button`                                                       | 28       |
| `TextInput`                                                    | 5        |
| `TextArea`, `Select`                                           | по 3     |
| `Loader`, `Icon`, `Checkbox`                                   | по 2     |
| `Toaster`, `Switch`, `Popup`, `NumberInput`, `Label`, `Dialog` | по 1     |

**Токены Gravity (`--g-*`) встречаются 8 раз на 5596 строк CSS.** То есть от
системы Яндекса взяты компоненты, но не её масштаб, палитра и типографика —
поверх написан свой слой.

## Типографика — самое запущенное место

Определено 8 размеров:

```
--font-size-caption      0.68rem
--font-size-label        0.72rem
--font-size-body-sm      0.75rem
--font-size-body         0.8rem
--font-size-heading-sm   0.82rem
--font-size-heading-md   1.25rem
--font-size-heading-lg   1.5rem
--font-size-root         14px
```

Используется **39 уникальных значений**. Из них через токен — 2 объявления,
остальные 123 записаны числом.

Хуже всего то, что **самый частый размер в проекте отсутствует в системе**:

| Значение    | Раз    | Есть в токенах?   |
| ----------- | ------ | ----------------- |
| **0.78rem** | **16** | **нет**           |
| 0.8rem      | 15     | да — `body`       |
| 0.72rem     | 15     | да — `label`      |
| 0.75rem     | 14     | да — `body-sm`    |
| 1rem        | 7      | нет               |
| 0.82rem     | 5      | да — `heading-sm` |
| 0.85rem     | 4      | нет               |
| 0.68rem     | 4      | да — `caption`    |
| 0.9rem      | 3      | нет               |
| 0.7rem      | 3      | нет               |

Шесть значений в диапазоне 0.68–0.85rem — это 10.9–13.6px. На экране они
неразличимы, но каждое живёт своей жизнью. Плюс смешаны единицы: `rem` и `px`.

## Цвет

- **57 уникальных hex** при семантической палитре из ~20 токенов.
- 7 литералов `rgba()`.
- Через `var(--color-*)` — 2 объявления, сырым hex — 53.

Палитра сама по себе разумная: `canvas / surface / surface-raised /
surface-hover`, `border / border-hover`, `text / text-muted / text-faint`,
`accent / danger / success`, плюс четыре цвета карточек персонажа.

## Отступы

Через `var(--space-*)` — 210 объявлений, сырыми `px` — **205**. Почти поровну.

Шкалы при этом нет:

```
8px×45  4px×39  6px×30  2px×26  12px×17  10px×15
7px×11  3px×10  5px×8   28px×6  24px×5   20px×4   14px×4   9px×3
```

Ни 4-точечная сетка, ни 8-точечная: значения 3, 5, 7, 9, 14 не ложатся никуда.

## Радиусы, тени, слои

- **16 уникальных `border-radius`.** Через токен — 19 объявлений, остальное
  сырьём: `8px`, `6px`, `4px`, `50%`, `999px`.
- **19 уникальных `box-shadow`.**
- `z-index`: в шапке `styles.css` описан аккуратный тир-лист со слоями, но в
  коде соседствуют `var(--arken-layer-popup, 1000)` и сырые `24`, `25`, `40`,
  `80`, `900`, `950`, `1250`.

## Конкретные дефекты, а не просто разнобой

1. **Разные fallback у одной переменной.** Встречаются `var(--radius-sm, 4px)`
   и `var(--radius-sm, 3px)`. Если переменная не определена, элементы получат
   разный радиус — и найти это будет трудно.
2. **0.78rem** — самый частый размер шрифта, которого нет в системе.
3. **Три набора переменных для одного и того же.** Любая правка палитры
   требует помнить про все три и про сырьё.

## Масштаб

| Что                  | Значение                           |
| -------------------- | ---------------------------------- |
| CSS всего            | 5596 строк в 4 файлах              |
| `styles.css`         | 4900 строк, 426 уникальных классов |
| Своих CSS-переменных | 57                                 |
| Inline-стилей в TSX  | 8 в 4 файлах — мало, это хорошо    |

Отдельно стоит отметить: inline-стилей почти нет. Разметка и оформление
разделены, и это заметно упрощает будущий редизайн.

## Что это значит для Pool 2

Порядок наведения — от того, что даёт наибольший эффект:

1. **Свести четыре набора токенов к одному.** Решить, что канонично:
   семантические `--color-*` или короткие псевдонимы. Второй набор используется
   в разы чаще, но первый читается лучше.
2. **Типографика.** Шесть почти одинаковых размеров свести к трём-четырём
   различимым, начав с `0.78rem` — он самый частый и его нет в системе.
3. **Шкала отступов.** Выбрать сетку и убрать нечётные значения.
4. **Радиусы и тени.** 16 и 19 значений — свести к трём-четырём каждое.
5. Только после этого — палитра и материал (Pool 4).

## Метод

Замеры воспроизводятся так:

```sh
grep -cE 'font-size:\s*var\(--font-size' apps/web/src/styles.css
grep -E 'font-size:' apps/web/src/styles.css | grep -vcE 'var\(--font-size'
grep -oE '#[0-9a-fA-F]{3,8}\b' apps/web/src/styles.css | tr 'A-F' 'a-f' | sort -u | wc -l
grep -oE '(gap|padding|margin)[a-z-]*:[^;]+' apps/web/src/styles.css | grep -oE '[0-9.]+px' | sort | uniq -c | sort -rn
grep -c "var(--g-" apps/web/src/styles.css
```

Повторить после наведения порядка — числа покажут, стало ли лучше.
