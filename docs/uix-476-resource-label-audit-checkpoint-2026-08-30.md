# UIX-476 — checkpoint подписей ресурсов в журнале — 2026-08-30

## Решения

- Источником текста системной записи остаётся серверный маршрут счётчиков;
  клиентские компоненты и горячие UI-файлы не менялись.
- Подписи берутся из актуальной раскладки характеристик той же кампании и
  только из строк с `source: "RESOURCE"`.
- Пустая или невалидная раскладка проходит через `resolveStatLayout`, поэтому
  стандартные ресурсы получают стартовые русские подписи.
- Если ресурс остался у персонажа, но его строку уже удалили из раскладки,
  журнал использует сырой ключ как безопасный fallback.
- Порядок нескольких изменений по-прежнему определяется сортировкой исходных
  ключей; замена ключа подписью не меняет стабильный порядок журнала.
- Дополнительное чтение раскладки выполняется только для операций с ресурсами;
  wallet-only правки не получают лишний запрос.
